# Sucree

A private, interactive one-year anniversary experience.

## Direction

Sucree is not a conventional scrolling love letter. It is a small cinematic memory archive built around touch, movement, photographs, real moments, and deliberate transitions.

The experience begins with one question:

> Will you be my girlfriend again?

Both answers are yes.

## Build phases

1. Foundation and visual language
2. Opening and renewal moment
3. Story engine and chapter navigation
4. How we started
5. The first yes
6. The first year
7. Picnic and little things
8. Growing together
9. Families
10. Camera roll
11. Anniversary letter
12. The future
13. Final moment and hidden memories
14. Motion, mobile, sound, performance and QA

## Stack

- React
- TypeScript
- Vite
- Motion
- CSS custom properties

The repository intentionally starts without a CMS or database. This is a private, authored experience, so the first build keeps the content close to the experience and leaves room to introduce a content layer only if it becomes useful.
